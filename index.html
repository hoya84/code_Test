도움말

기본 사용

  • 소스 창에 Markdown을 입력하면 미리보기에 바로 반영됩니다.
  • 폰에서는 편집 / 미리보기를 탭으로 전환하고, 넓은 화면(태블릿 가로 등)에서는 분할 보기를 쓸 수 있습니다.
  • 툴바의 서식 버튼은 좌우로 밀어서 더 볼 수 있습니다.
  • 입력 내용은 자동으로 임시 저장되어 앱을 닫아도 유지됩니다.

파일

  • 열기: .md / .txt 파일 선택 (PC에서는 파일을 끌어다 놓아도 됩니다)
  • 저장: 안드로이드는 다운로드 폴더에 .md 로 저장됩니다.
  • 내보내기: HTML 파일 저장, PDF는 인쇄 화면에서 “PDF로 저장”을 선택합니다.

단축키 (키보드 연결 시)

Ctrl+S저장
Ctrl+O열기
Ctrl+E / Ctrl+Shift+EHTML / PDF 내보내기
Ctrl+B / I / K굵게 / 기울임 / 링크
Ctrl+1 / 2 / 3편집 / 분할 / 미리보기

홈 화면에 설치 (안드로이드)

Chrome에서 이 페이지를 열고 ⋮ 메뉴 → 앱 설치(홈 화면에 추가)를 선택하면 앱처럼 실행되며, 설치 후에는 오프라인에서도 사용할 수 있습니다.
